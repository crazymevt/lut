# Bundled font

`NotoSans-Regular.ttf`, `NotoSans-Bold.ttf`, `NotoSans-Italic.ttf`, and
`NotoSans-BoldItalic.ttf` are Noto Sans faces from the Noto Fonts project:
https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans

Copyright 2018 The Noto Project Authors. Distributed under the SIL Open Font
License 1.1, reproduced in `OFL.txt`. The font covers Latin, Greek and Cyrillic;
it is not an all-Unicode font. Applications can select a different font using
the inherited `:font` style token. Raylib loads the codepoints used by the tree.
